# 图床

个人博客图床仓库，托管博客所需的各类图片资源。

## 目录结构

| 目录 | 说明 | 数量 |
|------|------|------|
| [`2d/`](./2d) | 二次元图片 | 23 |
| [`gif/`](./gif) | 动图（表情包、加载动画等） | ≈50 |
| [`hexo/`](./hexo) | Hexo 博客壁纸（日/夜、PC/移动端） | 4 |
| [`img/`](./img) | 博客文章配图 | ≈200 |
| [`screenshot/`](./screenshot) | 软件/操作截图 | ≈400 |
| [`tag/`](./tag) | 博客标签图标 | ≈45 |
| [`wallpaper/`](./wallpaper) | 壁纸（PC + 手机） | ≈30 |

## 加速地址

图片通过 Cloudflare 代理加速：

```
https://file.meimolihan.eu.org/<path>
```

例如：`https://file.meimolihan.eu.org/img/docker-01.webp`

## 使用

在 Markdown 中引用图片：

```markdown
![描述](https://file.meimolihan.eu.org/img/docker-01.webp)
```

## 许可

仅供个人博客使用，请勿用于商业用途。
